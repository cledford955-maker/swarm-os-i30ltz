# All text on this theme is the same size/weight and the same color —
# "20pt bold" everywhere per design direction (2026-09-18) — rather than the
# previous mix of 14/16/18/20pt. One exception stays functional, not
# decorative: the selected menu item is still visually distinct (inverted/
# brighter) so you can tell what you're about to boot.
# Color moved off the pure NVIDIA green (#76B900, still used as an accent on
# borders/selection) to a harder amber/warning tone — reads more like a
# hazard/swarm-alert palette than a stock "green terminal" theme.
#
# Swarm-attack imagery beyond what's below (big 3D per-entry icons, a
# wasp-tiled progress bar fill) needs real image assets GRUB can composite —
# it can't render vector/procedural art or animate. See the icon-generation
# prompt for those; drop the PNGs into ./icons/ and ./ once made and this
# theme will pick them up (icon_width/height below already sized for them).

# silhouettes there reads as "the swarm filling in" even though nothing
# moves frame to frame. fg_color/bg_color/border_color below are left in
# place as the plain solid-color rendering GRUB falls back to until
# highlight_style is actually set (uncomment once swarm_fill_*.png exists —
